The Correspondents

Four brothers. Four conditions. One war.

Four separate painterly windows — assembled in code into one scene, each grounded in the real moment he wrote from.

This is the recommended approach: four independent 4K renders (not one baked composite) so each window stays fully detailed, swappable, and — crucially — animates as its own breathing loop. A shared frame, color-key, vignette, grain and grade fuse them into a single polyptych. In the live build the panels breathe, then their dividers dissolve and the four converge into the Parallel Lives timeline.
